# ServiceOps iOS project guidance

- The canonical ServiceOps server project is always available at `smb://HOMESERVER-02._smb._tcp.local/project/ServiceOps`.
- When the share is mounted on this Mac, use `/Volumes/project/ServiceOps` to review current server code, API contracts, release history, and requirements relevant to the iOS app.
- Preserve the server repository as read-only unless the user explicitly asks for server-side changes.
